# 街口氛围候选检查

第一张氛围明显增强，但成了沿街透视插画：上窄下宽、地砖近大远小、建筑侵入行走面，也没有保留现有出口。不能作为可行走地图。正在用同图改成正交高俯视，不因氛围好就覆盖B视角。

第二张edit仍保留原透视几何，拒绝整图接入。换为正俯视地面氛围底图，建筑/门按现有地图组合，避免继续对同一错误参考微调。

地面版原图已生成并检查：改为不带深度收缩的正俯视铺地，加入暖窗光、冷侧影、砖面修补、排水沟和落叶。边缘仍带少量建筑，因此renderer只取 `40 64 728 1050` 平面区域，映射现有街口矩形，不改变任何存档、碰撞、转场坐标。第一、二张透视图均不被运行时引用。

这一步改善整片重复地砖和光色单调；建筑边缘、门/阶梯细节尚需继续补，不能据地面替换宣称场景美术完成。

实际renderer观察：原照相馆旅程过门到街口，背景正常载入；桌面和390×844均可见暖冷分区、细石缝、修补砖与落叶。主角与地面尺度可用，点地行走和门口动作正常。两侧现有程序化建筑边缘与新底图的细节水平仍有差距，作为下一项继续补，不把当前街口称为最终场景。
