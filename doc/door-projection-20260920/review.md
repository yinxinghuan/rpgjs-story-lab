# 侧门原生投影重制 · 2026-09-20

用户纠正：旧街是样本游戏，需要证明生成素材本身具备正确的俯视正投影。运行时纵向压缩旧正立面素材不能作为最终方案。

## 原因与新准入标准

旧 PHOTO STUDIO 门生成提示词要求 `STRICT FRONT ELEVATION`，与当前俯视场景冲突。此前运行时压缩仅是已被用户否决的临时实现，不代表素材准入。

新素材从斜上方观察竖直门扇，采用无消失点、水平无偏转的正投影。投影门面目标宽高约 3:4；门顶厚度、把手、铰链、玻璃与门面服从同一视角。不能只改变轮廓比例。

接入时按原生比例统一缩放，保留整扇门，不做非等比缩放、局部变形或裁掉上下门板。先检查原图，再验证实际场景。现有门的铰接方向与店铺身份沿用。

## 平台尝试

`photo/request.json` 为重新从文本生成的请求，640×640。请求 ID 为 `58baf564-1fcb-4eb0-bde7-e1a8b45ab390`。

平台返回 HTTP 502，`INTERNAL_ERROR`，`retryable: false`，消息为 `Upstream returned invalid JSON`，无图片和 task ID。详见 `photo/state.json`。未盲目重发终态失败请求。

随后通过内置 imagegen 生成单扇原始投影研究样片；此来源不能作为平台生成能力通过的证据。尚未替换正式素材或发布。

## 原始样片结果

- `photo/native-v1-too-tall.png`：门面仍偏高，俯视不足。
- `photo/native-v2-converging.png`：俯视明显，但两侧上宽下窄，存在不符合正投影的收敛。
- `photo/native-v3-orthographic.png`：生成工具重绘修正侧边平行，保留可见顶面及较短的门面，作为当前原生投影候选。仅复制工具原始文件，无后期缩放、拉伸、裁切或颜色处理。未作场景准入。

第三版提示词要点：`TRUE ORTHOGRAPHIC projection, eliminating ALL perspective convergence`；前门面左右侧边平行且垂直，顶部/中部/底部等宽；保留俯视相机与门板厚度，并重绘而非拉伸上一张图。完整生成指令保留于本次任务记录。

仍待完成：平台生图恢复后的同类请求验证、其余门款重制、原生比例接入及场景验收。不能把此单张候选声称为全部侧门完成。

## 用户选定基准（覆盖候选排序）

用户明确第一张 `photo/native-v1-too-tall.png`「除了稍微有点高以外，是最合适的」。此图成为门款基准，不能再以第三版宽扁造型替代用户偏好。

后续保留第一张的薄顶面、边框、材质、五金与店铺特征，仅通过生成工具重绘略高视角，目标投影高度约减少 12%，宽度保持一致。12% 是本次制作微调假设，并非用户指定数值。禁止机械压缩图像或运行时非等比补偿。

`photo/native-v4-selected-refinement.png` 是以内置 imagegen 引用用户选定第一张重绘的原始输出，未做任何后期变形。保持薄顶边、红棕木色及店铺特征，门面相对宽度略短；生成器也改变了对象在画布中的占比，因此不能声称精确实现同像素宽度或精确 12%。此版作为小幅调整候选供用户检查，尚未接入游戏。
