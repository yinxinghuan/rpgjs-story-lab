# 公共记录册与照片查看更新

## 发布内容
- 背包照片可原位展开查看旅程原图、已有线索和放置地点。
- 公共记录册分为查找材料、留下记录两项用途，明确比对条件、下一目的地、调查摘要状态和照片位置。
- 放置照片的前置条件就近说明；照片可以取回，撤下调查经过时会一并取回照片。
- 档案间整理桌指明照片应放在修表铺的公共记录册旁。

## 验证
本地类型检查、前端构建和 campaign commission 核心流程通过。生产组件合成 UI 测试覆盖390×844中文、320×568英文及图片缺失；核心流程包含写入、放置、取回、撤下。此更新未修改存档协议、后端规则、游戏UUID或平台目录。用户理解效果仍待真实试玩。

部署遵循同一提交的自托管主站与 GitHub Pages 静态镜像。上线结果以实际bundle核验记录为准；本文件不代替线上证据。
