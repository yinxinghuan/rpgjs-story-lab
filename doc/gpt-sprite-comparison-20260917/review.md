# 人物生成重复样本与混合制作评估

日期：2026-09-17。用户要求再次用 GPT 图像能力生成角色，判断是否有必要将 demo 预设角色交给 GPT、动态素材继续使用平台。

## 实验与证据

- 三次独立调用，完全相同提示词与参考原图，保留全部结果，未挑选成功样本替代失败样本。
- 参考是 `public/art/overhead/mechanic.png`，SHA256 与具体请求记录见 `experiment.json`；提示词见 `prompt.txt`。
- 三张原图为 `gpt-01.png`、`gpt-02.png`、`gpt-03.png`。工具没有暴露底层模型编号，因此只能归因到本次 GPT 图像工具，不能声称已验证某个 GPT-6 型号。
- 平台对照为 `../oldstreet-laundry-redesign/pose-preserving/candidate.png`：相同参考图字节、相同提示词，保持原 3×4 布局，仅改身份与服饰。平台本轮只有一次结果，尺寸与工具控制参数也不同。
- `review.html` 可切换四向、播放或逐帧查看。原图只按格裁切预览，没有修腿、镜像、变形、去底或脚点对齐。浏览器已确认四张图片加载、方向与播放控件可用；这不是游戏内移动验收。

## 结果

| 项目 | GPT 三次重复结果 | 平台本轮结果 |
|---|---|---|
| 四个朝向 | 三张均按正、左、右、背排列，未见方向串格 | 四向正确 |
| 身份与衣服 | 单张内基本一致；样本间发型、口袋与脸部细节有差异 | 单张内基本一致 |
| 俯视与像素质感 | 三张都较贴近 B 参考的头顶可见程度和纹理层次 | 比此前候选更接近参考，脸部较大、层次较平 |
| 前后迈步 | 正面与背面鞋端有交替 | 有交替 |
| 侧向走路 | 第一、三列轮廓和近侧腿姿态仍很相似，摆臂不足；不能认定左右脚语义正确 | 同样有此疑点 |
| 背景 | 未遵守纯洋红要求，直接输出带 alpha 的图 | 纯色洋红背景，仍需后处理 |
| 生产准入 | 三张均未准入完整行走素材 | 未准入完整行走素材 |

原参考本身的侧向迈步端点就很相似；提示词要求保持姿态可能把这个问题也带入了两条链路。不能以本实验判断某类族裔更难生成，也不能把参考错误解释为模型能力上限。

alpha 实测见 `image-facts.json`：每张约 119 万个完全透明像素；人物多数非透明像素在 alpha 240–254，另有低透明度边缘。不能把“多数像素非 255”直接等同于整个人物透底失败，也不能仅凭透明背景断言边缘合格。后续需在亮、暗场景分别观察。

这是同一个身份的三次小样，能说明本次造型重复一致性，不能估计全体角色平均成功率。尚未证明不同体型、服装、肤色、年龄以及连续移动都稳定。

## 决策与下一步

1. 保留混合制作作为近期交付备选。GPT 可以承担难产的预设人物外观，但每个会行走的人物仍必须通过四向、左右脚、摆臂、脚点、透明边缘和真实场景移动准入。暂不整批替换现有角色，不改玩家旧存档中的身份。
2. 下一项最有区分力的实验是校正侧向姿态参考，再用同一套明确标注左右脚与前后摆臂的参考分别测试。优先解决共有的输入问题，不继续堆叠身份描述或无目的重复生成。
3. 达到准入后先替换一个预设 NPC，在当前相机和移动速度下观察。其他预设角色再沿用通过的合同；不要求再跑每条剧情路线。
4. 动态场景、道具、插图继续走平台。动态人物的外观生成与可行走动作是两项能力：动作未通过时用已审核的动作模板/合适的站姿互动，不把未合格的 12 格图直接投入行走。用户已决定先验证正确执行，细节随后打磨。
5. 即使 demo 预设角色全部由 GPT 制作，也只能证明游戏与运行时扩展合同，不能宣称平台已经能端到端生产全部角色素材。两种来源要继续分别记录。

## 平台升级与 LoRA

LoRA 是值得保留的研发方向，目前没有证据证明“必须先训练 LoRA 才能继续交付”。先固定可重复的参考输入与姿态合同，再以失败类型决定升级。

- 风格、像素尺度、俯视、人物比例不稳：考虑兼容基础模型上的 LoRA / 参考图条件控制。
- 左右脚、摆臂、朝向错误：需要显式姿态/结构控制和逐帧一致性检查。LoRA 本身不保证动作正确。
- API 层首先确认底层模型是否允许训练和加载适配器。当前已读取的媒体接口没有公开 LoRA 或姿态控制字段，不能假定现有闭源服务可直接加载。
- 数据集仅收审核通过的原图/帧，标注朝向、左/右支撑腿、迈步阶段、脚点和视角，避免把错误基准训进去。角色级留出验证，比较整套动作通过率、参考一致性、生成耗时与重试成本；不只比较单张漂亮程度。
- 本轮仅做规划，没有启动训练、上传训练集或修改平台服务。

资料：[Diffusers LoRA](https://huggingface.co/docs/diffusers/training/lora)；[ControlNet 的边缘、深度与姿态条件](https://huggingface.co/docs/diffusers/using-diffusers/controlnet)。以上是工程建议，不是当前平台已支持这些能力的声明。
