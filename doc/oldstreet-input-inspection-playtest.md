## 钟底观察正向流程

同一 Worker 测试旅程经 UI 移开空盒、拿放大镜，从街口 → 照相馆 → 屋顶 → 河边工作棚，选择帮忙送钟。首次可见介绍后人物标签变为老周，旧钟进入背包。抬起插销，经合住院捷径回修表铺。

在抽屉输入“检查钟底”，自动打开“看看钟底”原生对话框。选择观察右下，实际窄屏截图能清楚看到一对鸟形刻记；选择“一对燕子”后特写关闭，显示发现文本。打开“随身与发现” → “发现”，确认“钟底的刻记”和“院门捷径”，没有未取得的照片发现。关闭记录后成功发起走向合住院的行动。全程使用实际 UI，无存档事实注入。

顺路发现关闭院门在工作棚一侧仍提示“插销在工作棚那一侧”；现区分方向，工作棚一侧明确提示抬起插销，院子一侧保留路线信息。照片自由输入正向流程、真实平台与精确手机尺寸仍未由本次证据覆盖。

## 照片输入、拒绝重试与完成

选择候选 1 并拼合，返回边缘不匹配提示，特写保持打开，照片仍在背包；改选候选 2、不旋转后拼合成功，特写关闭，显示洗衣店旧店面的发现结果。实际构图已检查，但照片自身中央接缝仍按既有候选素材质量记录，不代表整套正式美术准入。
