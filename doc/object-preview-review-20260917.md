# 重要物品特写恢复

用户要求保留已有特写，重要物品可看细节，不要求每个家具都有。核对发现钟底、拼合和显影专用特写仍在；本轮补普通物件共用图示层。

抽屉、小格使用已有透明精灵三态，主动查看后显示紧凑实物图；点“近看物品”打开只读放大。返回同一物件行动面板，关闭探索后预览消失。原有行动不要求先放大，解谜仍使用自己的专用界面，没有生成或编辑图片。

本地 renderer 实操抽屉：闭合预览→放大→返回→移开盒子→放大镜状态→拿走→只留收据→返回探索。模态期间摇杆禁用，关闭后恢复；正文、标签、图像与权威结果同步。截图在 `_qa/ui/object-preview-20260917/`。

浏览器请求390×844，但本轮DOM实测300×649；截图进一步存在显示缩放，按真实观测记录，不能称390／320完整尺寸验收或iPhone触控通过。默认viewport已经恢复。专用钟底／照片机制沿用既有证据，没有重跑所有谜题。

完整构建通过。全量UI静态扫描仍有历史构建产物／旧代码字符项，本轮新增预览组件无命中，不宣称全项目UI扫描清零。整体UI仍需后续真实手机与边缘通路检查。
