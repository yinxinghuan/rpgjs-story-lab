# 单人游戏正式交互重整

状态：用户试玩指出正式体验不合格；本文是实施计划，不是完成记录。继续现有主游戏，保留 B 视角、摇杆与点地移动、原存档和权威行动规则。此前流程能走通的验证不等于玩家能理解。

## 已确认的问题

- `src/original-game.tsx` 的人物面板混合人物资料、行动、交谈/输入行动切换、在线服务开关、模型数据说明和常驻输入框；没有供普通玩家直接选择的交谈话题。
- 对白沿用通用弹层与“下一句/完整记录”按钮，交谈成为阅读工具操作；玩家回应和人物回应缺少连续关系。
- 场景 `.og-marker` 对没有独立角色/设备素材的实体显示加号；非人物标签用 `String(i+1)`。因此“3”是当前实体列表序号，不是数量、等级或任务进度。也会覆盖背景内已有对象。每个实体需分别核对，不能一概解释成等待生图。
- 预设交谈服务只识别问候、目标、担心和回忆，不能仅添加外观不同但无具体内容的通用按钮，假装人物交谈已经完成。

## 正式体验合同

### 地图探索与物件

地图默认呈现世界和人物，不显示实体编号或通用加号方块。背景已有的装置直接设点击范围；独立装置使用已准入素材；确实缺少可辨认对象的必要交互补齐对应素材，不能用不可见热点掩盖缺失。

走近后物件获得轻量轮廓/亮度提示，右下角显示具体动词，如“检查启动机”。一种明确且已说明代价的行动可直接执行；多种选择打开紧凑行动列表，每项使用玩家看得懂的动作及实际代价。不会因走到目标位置自动执行消耗行动。必要线索需保持可发现，“附近”作为辅助，不代替场景表达。点击不可达对象给简短原因，不弹技术错误。

### 人物交谈

走近人物并交谈后，保留人物和场景背景。屏幕下部出现独立于背包/日志的无尖角、无三角箭头对话区域：人物名字、一段自然短对白、当前可选回应。非人形或缺少合格肖像时使用名字与场景人物，不临时生成不一致头像。

优先显示 2–4 条与当前人物、地点、已知事实和进度相关的话题或回应。选项区分“询问情况”“表达态度”和“承诺行动”；提问不会冒充执行修理或消耗物品。必要时少于两项，不能为了凑数量虚构话题。选择后呈现玩家刚选的话和人物回答，再更新下一组回应；已完成事项不重复当新任务，未来角色不提前出现。

正文以自然句群呈现；一般一段 1–3 句，短屏可滚动，不机械按固定字符截断，不自动跳过。取消可见“下一句”“完整记录”控件；确有连续的长事件采用轻点对白区域/键盘继续及克制的继续提示，选项只在对应内容后出现。剧情动作结果可表现为简短叙述，不为每次行动制造“眼前发生的事”通用弹窗。

“说点别的”是次级入口，点开后再出现输入框；展开前不占用键盘空间。可明确退出交谈回到地图，结束时清空移动输入，避免角色突然继续走。历史自动进入日志，不在每段对白中提供全文阅读入口。

### 设置与技术信息

正常交谈移除“在线交谈已开启·点击关闭”“输入当前支持目录完整句”等测试措辞。自由表达相关设置放入独立次级设置，以玩家可理解的功能说明呈现；必要的数据发送说明保留在首次主动启用/设置处，既有选择不擅自改成默认外发。

技术诊断仅在明确诊断入口出现，主日志优先显示旅程内容。错误用简短可恢复反馈，不显示内部错误码、测试预算或校验术语；详码可留诊断。限制和未开放功能不能谎称可用。

## 实施顺序

1. 审计九场景所有实体，登记“背景已有 / 独立已准入 / 真实缺素材”、动作入口、可达性和后果；同批移除玩家层实体编号与测试常驻信息。
2. 在现有主游戏完成阿达的开场交谈、一次话题选择、人物回应、修理行动和回地图；话题与既有权威事实绑定，补预设具体回应与模型约束，不只改按钮文字。
3. 将同一对话结构覆盖其他已登场人物、再次交谈、关系变化、结局后状态和失败恢复；物件统一紧凑行动选择，自由输入保持补充地位。
4. 核对移动/面板切换、键盘遮挡、返回、等待、离线与重复点击；完成手机尺寸和实际 AlterU 从开场至关键选择的试玩，再同提交双部署。

## 验收

- 不手动输入也可完成主线；每个人物首次交谈都有有效回应入口，不出现空白输入要求。
- 选项属于当前已知情境，询问不扣行动资源，真正行动仍走原权威验证并只结算一次。
- 主画面和常规对白无实体序号、加号占位、在线测试开关、内部诊断文案或全文日志按钮。
- 物件可看见、可找到、可接近、可操作；移除标记不造成隐形任务。
- 320×568 和 390×844、中英文本、软键盘、等待和错误都可操作；长对白可读、可返回，地图人物不被无必要的大弹窗覆盖。
- 实际 AlterU 验证选择话题→短对白→后续回应→行动→地图结果→退出重进；自动测试不代表理解验收通过。
- 原存档、剧情资源、关系和既有素材版本不被重建。完成标准是连贯游玩，不是截图或单个组件通过。
