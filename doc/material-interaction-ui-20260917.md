# 材料交互与旅程菜单：本地界面验证

本轮属于 UI 收口。动态主线只保留开发候选入口，未发布、未改写原旅程，也没有调用真实模型或媒体服务。

## 发现与修复

- 材料准备中的状态查询断线后，原按钮仍因 planning 状态禁用，无法恢复。现在提供“重新连接”，只读同一份结果；服务确认失败后才允许显式重新准备。首次状态查询未完成不能发起准备。
- 材料面板使用固定标题/关闭、滚动正文、固定底部选择；英文长标题和两项选择可换行，两个按钮等高。取舍说明缩短，保留交给家人或留存原件的区别。
- 实际游戏旅程列表在320宽滚到底部后，旧版关闭按钮消失。现在固定头部，仅下面的内容滚动；点击收起回到原地图。没有调整世界比例、跟随镜头或角色尺度。
- 材料面板打开时地图点击、摇杆和居民暂停。正常旅程菜单没有新主线测试按钮；候选只在本地能力已启用且 debug 模式下出现。

## 浏览器证据

使用 CUA 的真实浏览器渲染与点击；截图已在本次工具结果中检查，未保存为本地图片文件。

- `/_qa/campaign-view.html` 使用实际 React 组件与合成内容，不访问任何模型/旅程接口，未加入正式构建入口。
- 320×568英文：准备→查询失败→重连→准备完成，准备请求始终1次，读取4次；收起再打开读取5次、准备仍1次。
- 320×568英文：三条记录滚动、错选提示、滚至第三项并选中，关闭与返回始终可达；按钮至少44px，页面无横向溢出。
- 320×568与390×844英文：纸袋说明和取舍按钮已截图检查、修正样式继承导致的按钮宽度/高度不一致后复验。320中文控件及“留下原件”完成反馈已检查；合成纸袋正文仍为英文，不计作中文生成内容验收。
- 实际主游戏：390×844旅程列表、320×568滚动到底部后关闭仍可见；点击收起无横向溢出、回到原街口。外部访客栏正常出现，可通过自身关闭按钮关闭；未改生产页面隐藏它。

## 核心恢复验证

新增合成后台测试：准备过程中正常转场不会被后到结果覆盖；重复准备、重新创建任务管理器和重复提交回执不会再生成；超时后需明确重试，旧请求晚到不能替换新结果；排队后服务中断不会永久等待。

新增客户端测试：新主线创建回执丢失后，恢复相同请求、语言及主线选项；本地未开放新主线时，拒绝不会阻塞原旅程继续。

这些测试证明恢复与提交机制，不证明模型故事质量、自由输入全链路、真实手机触控或真实平台网络。材料视图当前只有合成组件检查，第二阶段仍需真实内容进入实际地图后的完整两段体验。

结果：本轮相关24项测试通过；正式构建、9场景/27资源SHA校验、Worker启动检查和源码/暂存内容/产物凭据扫描通过。两个修改视图的UI基础扫描无发现。全目录UI扫描包含大量历史dist和第三方库结果，不作为本轮界面通过证据。
