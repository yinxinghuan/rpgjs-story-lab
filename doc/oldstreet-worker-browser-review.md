# Worker 通信浏览器试玩 · 2026-09-15

入口：同一游戏 localhost:5453/?debug=1&session=worker。不是独立游戏或新 UUID，不是线上主站。前端调用 oldStreetSessionHttp，Vite 本机适配器剥掉 UUID 路径后交给实际 Worker handler/DO 类，本地 SQLite 持久化。

CUA 实际操作走完：街口 → 照相馆 → 屋顶 → 河边工作棚 → 问候并借钥匙 → 抬起插销 → 院门 → 修表铺 → 打开小格 → 拿信 → 街口 → 带信回家 → 确认回家。

观察证据：借钥匙前只有未知修表师位置，借钥匙后可见介绍与“老周”名称；院门由关闭变为可通行；小格由锁住变有信、拿取后变空，背包同时出现信；最终“信已送到”，明确仍带着未归还钥匙，不额外计入照片和旧钟支线。刷新后同一结局、同一未还钥匙仍存在，普通地图动作禁用，重新探索按钮可见。
