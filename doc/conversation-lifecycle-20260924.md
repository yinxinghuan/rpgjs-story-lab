# 连续对话与话题生命周期 · 2026-09-24

本轮按用户要求先调整三款，再把实测规则写回技能；尚未提交/发布这些对话变更。保留各项目原有未提交工作。

## 实现
- 新增一致的 conversation-flow 核心：普通话题成功回答后隐藏；父节点完成后开放追问；显式证据变体重新开放；utility 帮助保留。
- 三款主要人物共 11 名，每人至少一条三轮作者话题链。普通追问不触发道具、关系或剧情；原有合法效果仍走原入口。
- 记忆余量 IndexedDB 成对问答、金融游戏本地旅程 history、旧街服务器 blocks 都保存 topicKey。历史不再按 24/60 条静默丢弃；UI 分页查看更多，模型上下文仍有限。
- 旧问答仅精确中英文成对匹配后标完成，失败/不完整不消耗，不能恢复旧版本已裁掉的记录。
- 连回应为空题时的交谈组件消失风险已处理；自由输入与回看保持可用。
- 金融游戏决定后的回应也进入生命周期；谈交易条件仍属服务操作，不因聊过隐藏。

## 验证
- 记忆余量 37 项测试、金融游戏 22 项测试通过；旧街相关 271 项回归通过，最后共享照片变体调整另跑 16 项归档/生命周期回归通过。
- 三款各 390×844 / 320×568 真实浏览器：一名人物连续三轮、旧题消失、刷新后不复活、回看记录。全部通过；11 名三轮链另有数据测试，不冒称所有人物逐轮触控遍历。
- 记忆游戏 UI 从已介绍人物的测试档开始；金融游戏从新旅程正常介绍开始；旧街使用本地真实权威 API 建立测试场景，不是前半段步行路线验收。
- 三款构建通过；原生 iPhone 键盘、线上新版本及独立 agent 制作新游戏未验证。
- 全量旧项目混合测试曾受沙箱 HTTP 监听限制，不报告全仓全量通过；获准在本地监听后运行的旧街相关套件全部通过。

## 未夸大的边界
本轮实现有限作者话题链，不是模型自由生成无限分支。中断后可回看已提交回答并继续追问，没有逐字阅读光标恢复。章节规模使用完整历史，长篇游戏仍需存储层分页与独立 completed ledger。P1 通用美术装配工具及独立交接考试是后续工作，不计入本轮完成。
