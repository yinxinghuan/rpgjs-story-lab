# 留一盏灯 · 正交空间视觉合同

## 1. 视觉命题
雨夜停驶的列车，由玩家亲手修复与求援，一盏盏恢复可依靠的光。延续用户已认可的狭长车厢、两侧铁路、蓝布座椅、旧橄榄金属、黄铜暖光与黄雨衣。

## 2. 构图与相机
384×576 世界，正交 2D JRPG，平行边线，无消失点、无近大远小。车体约 116×528，占画面宽约 30%；两侧非行走环境表达铁路身份。人物 .14 图集尺度，主体高约 39、宽约 20，脚底碰撞 9×15。

客厢内宽 84，五排共十个 24×30 单座，排距 56、中央净通道 36。行李车内宽 96，三个沿墙 24×24 货箱，保留中央路；驾驶室内宽 84，可行动区从 y240 开始，控制台在前端凹槽，后部有 24×30 座椅。不同空间仍使用同尺度主角。

## 3. 颜色
背景 #08111b，外景 #16283e，UI #111e2c，正文 #eee4ce，次要 #b7b2a3，黄铜 #b59657，暖灯 #edc77a；连接成功用两盏青绿设备灯并辅以文字。颜色不是唯一状态提示。

## 4. 排版
中英 Georgia/系统宋体，辅助 system-ui。对白/日志 16px/1.65，小屏不缩成 12px；主行动 14px，辅助 11–13px，地点 9–11px。短分页中文 44 字、英文 110 字；长内容可滚动，菜单固定在视口内。

## 5. 形状、材质与光
深蓝布面、磨损金属、细黄铜边框；游戏家具保持直角/轻微圆角物体形状。UI 2–4px 角，44px 最小点击区域。主灯暖、窗外冷，不增加无语义霓虹特效。维修后 600ms 内加强背景/物件光感；降低动效时直接切换。

## 6. 素材与状态
三张独立背景 carriage-narrow、baggage-car、driving-cab。背景不烘焙人物或可变物件；静态座椅与货箱独立实例。原角色与物件仍用真实 RGBA 图集，逐帧/逐状态裁切与脚底锚点。

新增 train-equipment 是生图工具直接生成的全幅不透明矩形设备图集：货箱表面、调度板、电池、电台无电/有电/已连接。作为实体矩形表面消费，不伪装成透明抠图。库存与装入电台后的电池保持橄榄方形外壳/黄铜接线柱身份。图集实际分界不均匀，读取真实 crop，不能假定请求的 512 等分成立。

器材柜使用原空柜状态层，未取电池另叠电池贴图。电台无电槽空；装入后方形电池与一盏琥珀灯；求援后再亮两盏青绿灯。调度板读前/读后外形不改变，知识与日志变化由正文表达。

## 7. UI 与图标
地图是主舞台。顶部地点、标题和任务；同一套自定义线框 SVG 表示路线/背包/日志/设置，44×44 触控。路线只显示已到访地名与当前位置，未知区域显示“尚未抵达”，不提供传送。

普通器材柜开柜/取物用短提示；检修柜和电台使用同图集物件特写，NPC/调度记录使用底部对白；电台两颗具名频道按钮，可选展开自由输入。实体名称字幕不参与额外命中，NPC 名称位于左侧，避免覆盖配电箱。转场遮罩直到实际 RPG-JS 地图与玩家就绪才撤下。

## 8. 动效与声音
主角步态以实际行走距离为时钟：每 55 世界像素完成一个左右脚周期，按左迈步→并脚→右迈步→并脚循环；步速仍为 110 世界像素/秒。寻路节点之间连续移动，减速时脚步同步放慢，碰墙停止、到达或打开面板时恢复站立。帧率或手机像素密度不改变步幅。
输入同帧反馈；寻路落点标记，阻挡有短反馈；按下/焦点可见；菜单/对白焦点受控并在关闭后恢复。声音默认关，依赖手势解锁，提交成功才播短音；没有配音/循环音乐。prefers-reduced-motion 下禁用过渡动画，保留结果。

## 9. 参考转译
参考 RPG-JS 官方 starter 的正交格子、地图角色与接近互动语法，保留真实 RPG-JS renderer/Tiled/地图事件。当前直接移动适配器和 React 对话壳是为共享叙事碰撞/手机可读性所作集成，并非完全照搬原生多人输入或 showText UI。

## 10. 反模式
不把车厢扩成大厅，不为了占满画布扩大室内；不让远处物件更小；不把透明棋盘格 RGB 作为贴图准入；不把库存电池变成安装后的保险丝；不以 React 名称/热点消失冒充实际引擎转场完成；不在模型文字里创建设备/新人物；不隐藏未通过的运行问题。

## 11. 切片验收
三个区域同尺度；所有物件/门可达；十个客厢座椅、货箱、车壁与固定设备边界一致；林位于客厢、周雨位于行李车，往返后保持对应实体。完整修复→电池→记录→装入→错频道→正确频道→往返/刷新流程；390×844、320×568、1440×1000 地图及对白/库存/路线/英文菜单实际截图。素材许可证随构建分发。

## 已锁定的当前交付方向

采用 orthogonal-overhead-b-v1：B俯视图集、正交狭长车厢与两侧外景。黄雨衣主角、灰衣林、青衣配米色围巾的周雨；许岚仅通过电台出现，不创建实体人物。九项当前素材基线不再生图替换。

界面采用A信息结构、B临时提示、少量C黄铜材质用于设备特写。手机全屏铺底并等比跟随；桌面操作区单行三列。人物物理像素缓冲随地图CSS尺寸/DPR调整，最高5.2倍，不改变世界比例。落点显示正圆环。关闭特写统一写“返回地图”。

Pages设置明确说明本浏览器存档与预设对话，隐藏在线模型选项。发布保留平台guest-shell；外部访客栏不作为游戏安全区，不为它修改地图镜头。

### 物件与人物的前后关系
