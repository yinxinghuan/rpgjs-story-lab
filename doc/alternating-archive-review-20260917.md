# 动态档案间：交替通路验证

## 本轮实际变化

生成房间的摆放意图新增 `switch-left / switch-right`，与已有无架、普通左移、普通右移并存。前一种架位挡索引，移动后露出索引但挡日志；玩家可以选择先读日志再移架，或先移架读索引再移回。两份已读证据进入同一旅程，随后完成原来的调查，不要求额外往返次数。现场家具、碰撞、可操作对象与自由输入行动同步，普通移架及旧旅程布局保持原样。

两种状态都验证架子、整理桌、出口和当时露出的记录可达。日志外借与交替通路不兼容，在准入时明确拒绝。生成提示已经列出新意图与适用条件；本轮没有新真实模型/媒体调用，不能把本地合成作者选择说成模型多样性实证。

## 验证与发现

- 19 项相关检查通过：包含普通与交替摆放、不同种子的实际可达布局、两种读取顺序的权威行动、已读证据/架位恢复、重复提交、被挡住目标不可操作、外借冲突拒绝，以及既有主线/结束条件。
- 本地实际 renderer 先走“移架→读索引→刷新→移回→读日志→整理”，再走“先读日志→移架→读索引→整理→移回→自然门离开”。前置旅程由测试服务通过正常权威行动准备到未读档案间；不是从开场完整试玩，也不是新实时生成内容测试。
- 首轮发现长机关说明被当作地图目标名称，已改为短名称；说明只在主动查看出现。同一描述也进入当前房间的自由行动知识。
- 首轮窄屏提交答案后保留旧滚动位置，结果在屏幕上方不可见。已修复完成态正文归顶；复验提交前 `scrollTop=262.69`，成功后为 `0`，结论立即可见，关闭/继续探索固定可达。
- 测试浏览器存在 1.3 显示缩放。最终校准并通过页面读数核对实际 `320×568`、`390×844` CSS 视口，不以工具标称尺寸替代真实尺寸。图片输出仍带浏览器捕获缩放，尺寸判定以记录的 CSS 读数为准；未修改产品布局规避测试工具问题。
- 测试夹具最初没有实现可选便笺查询，导致结果页显示连接错误。补齐夹具的现有任务接口后不再出现；不是生产接口修复。夹具使用内存数据库，重启新轮次使用独立端口，不修改真实玩家存档。

证据：`_qa/ui/alternating-archive-20260917/` 下 `shifted-390-platform-layout.png`、`restored-390-platform-layout.png`、`interaction-320-platform-layout.png`、`complete-320-platform-layout.png`。访客栏通过自身关闭按钮收起，未往生产代码加入隐藏规则。

完整构建通过，包含 9 场景/27 资源 SHA 与 Worker 启动检查。既有列车媒体引用和 bundle 体积警告仍在。公开凭据扫描通过。全项目 UI 静态扫描仍有历史产物/旧代码字符图标报告，不能记为全项目 UI 门禁已清零；本次未增加功能字符图标。

## 未完成范围与下一步

交替通路是一个已跑通的空间机制，仍不能单独证明完整动态章节、故事多样性或45–60分钟体验。调查的最终解题仍是排序；下一步应将可用空间操作放入整段生成事件的目的、线索与选择后果中，并用两份真实连续旅程验证整体差异，不再围绕同一个储物架加更多小步骤。真实 iPhone 键盘、新玩家理解与生产网络整合仍未验收；本轮仅保存开发分支，不发布正式站点，不进入旧技能打包。
