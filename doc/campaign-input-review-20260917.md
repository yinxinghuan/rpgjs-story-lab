# 动态主线自由输入接线验证

本轮为第二阶段增量，未发布、未调用真实模型或媒体，不代表完整动态主线交付。

## 核心机制

`_qa/old-street-campaign.test.ts` 新增实际 SessionAuthority 路线：通过既有门、借钥匙和取信行动到达记录册，注入合成自然语言解释结果，查阅→选错→指定正确记录→借车清路→地下室→先取照片夹→阅读寄存材料→带走原件。检查：未读知识不泄露、两条错误记录仍被提供、错误比对不推进、后一个内容承接真实选中记录、原件只领一次、同请求回执重放不重复理解/生成、取走照片夹后不把寄存架称为空架。测试只推进合成时钟以模拟跨场景耗时，不改变生产调用限额。

另一测试验证疑问只提交短尝试记录而不选择材料；现有旅程没有新的材料菜单或主线门槛。线索回看从权威已观察实例投射，取舍之前目的指向记录册/地下室，之后才允许回家。查阅与丢回执恢复能选出本次短段落，不因刷新串入其他历史。

30项定向测试通过：campaign、attempt、turn、journal。解释器注入结果不等于真实模型理解通过；后台异步任务的失败/恢复测试沿用同一测试组。

检查实际生成器路径时发现英文意图过滤会把含 and 的双特征描述也标为复合动作。现已仅在记录选择动作中屏蔽被选记录的完整名称或明确双特征引用，再对周围句子保留原否定/复合意图检查；原句仍交给语义审查。用脚本传输经过真实生成器验证“双特征描述”可通过，否定和追加领取动作仍被否决。这证明过滤与接线，不证明真实模型能可靠理解所有自然说法。

## 页面实证

使用实际 `OldStreetCampaignView` 与 `OldStreetJournalView` 的本地组件夹具 `_qa/campaign-view.html`，无模型、存档或媒体请求。选“留下原件”后关闭材料，再打开随身发现，寄存条、三条记录、选中记录、材料内容和原件去向可见。

320×568 首次截图发现英文 Discoveries 挤出按钮。已改短标签 Notes，并让列表独立滚动、标题/关闭/页签固定；同状态复验后标签完整，滚至最后一条仍能关闭，正文和选择去向清晰。390×844 DOM检查无横向溢出，关闭按钮为约67×44；该尺寸截图遇到调整后的画面比例不同步，不作为完整视觉通过证据。截图仅工具内显示，不声称存在磁盘图片。

夹具检查不等于主地图动态旅程端到端测试，也不代表真实iPhone或平台验收。下一步接通并实测本地地图候选旅程，以及获得有效授权后的真实生成与理解，继续扩充完整探索主线。
