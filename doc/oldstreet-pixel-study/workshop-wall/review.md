# 修表铺墙面候选

目的：在不改变地图/通行规则的前提下补充房间用途辨识度，保持像素候选入口。

平台源图 896×256，原图与请求、任务、哈希保留。实际空洞为约 x350..540，并不符合提示词的 x400..591，不能把源图直接铺到地图。候选分别采样左区域 0,0,348,256 和右区域 542,0,354,256，通过地图北门位置计算两侧显示范围。源图片不修改，没有上传新静态站点或调用新服务。

在当前空间，地板为 x80..304、y80..496；北门 x204，装饰仅位于 y16..80，两侧保留 x180..228 的空隙。碰撞、寻路、出入口及到达点仍由 old-street-space 提供。墙面是静态背景，不创建可拿走的钟表/工具，不替代任务中的旧钟。

实测：5456 独立旅程走到北门前，关闭外部访客栏后查看约 365×676 构图，钟表、罐子和工具板可见，人物及门口清晰；通过右下角入口往返合住院。原 5455 用户旅程未执行剧情操作。

机械检查：两侧区域不侵入地板、不覆盖权威北门；实际采样像素没有品红占位色；原图裁切范围均在图像内。67 项探索回归通过。

候选限制：两块墙面横向缩放不同，像素颗粒尚未完全统一；生成图带有绘画式墙面纹理和灯光，没有严格遵从不发光要求。当前只作环境构图候选，不视为生产美术准入，也未完成精确手机尺寸或平台实机验收。后续应由统一尺度的墙面模块替代非等比适配；不为这次候选改变已认可 B 视角或整套地图。
