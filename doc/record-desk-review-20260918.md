# 公共记录册交互整理

## 问题与调整
此前寄存条比对、调查摘要公开、照片放置混在同一个长面板里。现固定标题“公共记录册”，分“查找材料 / 留下记录”，按当前调查阶段默认选择用途。
- 查找：明确标记、包扎两项特征，匹配后显示记录名称及地下室资料架下一步；可回看原始依据。
- 留下：调查经过、相关照片分别展示状态和操作。未查清时指出去哪里整理；未写入时明确照片为何不能放置。
- 结果：留下是可选，照片离开背包后可取回；撤下经过也会取回照片，操作前说明。

## 验证范围
- 生产组件在本地合成 UI 页面运行：390×844 中文首次比对、找到记录、留档未就绪、写入与放置；320×568 英文写入、放置、撤下并取回。没有横向溢出。
- 本地权威服务 campaign commission 核心测试通过（包含放置/取回/撤下/重复提交与结束持久化），没有新增真实模型或媒体调用。
