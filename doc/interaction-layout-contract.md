# 统一探索交互布局（2026-09-17）

用户纠正：UI 优化先解决信息结构，不再在常驻面板上逐项补丁。此合同优先于此前“本地 UI 基线已完成”的结论。复用已认可 B 视角、满屏相机与纸色/暗色风格；游戏规则、角色及已有存档不变。

## 三种界面状态

| 状态 | 常驻内容 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 探索 | 全屏地图、顶部地图/物品/旅程、左摇杆、右行动按钮（目标名称＋动词） | 默认/关窗/移动/转场 | 主动按行动按钮 |
| 互动 | 有明确目标的底部面板，短说明、预设选项、自由输入；关闭固定可达 | 靠近后主动按右行动按钮 | 关闭、右下“继续探索”、开始移动、转场 |
| 特写 | 当前物件的解谜/材料/图片界面，单一关闭入口 | 从行动按钮或已打开的互动选项进入 | 关闭返回探索现场 |

- 靠近只是更新按钮和物件指示，不打开面板，不自动解释或执行操作。
- 地图点击物件/门/人物只寻路至接近点；真正调查/交谈/转场由同一个右下按钮触发。地图背景仍点击移动，摇杆保留。
- 非门物件先展开上下文及可用操作，不能在玩家尚未看到选项时自动拿走物品。未知人物可在主动交谈时完成介绍；已认识人物展开话题。
- 材料阅读、动态房间准备、照片生成统一挂在物件互动内部。任务状态独立于是否展开；重新打开读取原进度，不重复请求生成，不自动弹窗。
- 行动结果留在本次互动；恢复旅程/走不过去等非互动短反馈用短暂提示。首次委托和连接故障是显式独立状态，不伪装成附近物件触发。
- 互动绑定发起时的目标，不随附近另一物件变化偷换标题或选项。

## 布局与兼容

- 世界始终占满视口，HUD/面板绝对叠放，开关面板不改变世界大小或相机边界。
- 顶部保留工具区；底部控制区位置固定。行动按钮内目标名和动词两行，目标名过长可截断但可访问名称完整。
- 移动端互动面板不超过约半屏，固定标题和关闭按钮，长说明/选项在内部滚动；手机键盘缩短窗口时优先输入及发送，右下按钮仍可返回探索。
- 宽屏面板与操作区限宽，保持地图可见；所有主要控件≥44 CSS px，320×568、390×844及宽屏检查。
- 特写的长内容滚动不挤掉确认/关闭；外部访客栏不影响游戏内部布局。

## 本轮验收

用代表性人物、普通物件、出入口和动态显影台验证同一机制。经过不弹窗、点击物件只走近、右下按钮才开启、目标身份一致、选择与结果明确、关闭/移动后恢复无面板探索。验证关键状态转换而非重复所有路线。真实 iPhone 软键盘仍单独标为未验证。

## 全界面评估矩阵

| 界面 | 何时需要 | 系统规则/当前发现 | 验证方式 |
| --- | --- | --- | --- |
| 顶部工具 | 玩家主动找地图、随身、历史旅程 | 保留稳定三个入口，不显示实现/网络开关；打开后暂停移动，关闭回现场 | 320/390 三个入口及返回 |
| 附近行动 | 角色接近物件/人物/出入口 | 单一按钮＋目标名称；地图轻描边对应，不自动展开说明 | 人物/物件/门三类状态 |
| 对话与普通物件 | 主动按行动按钮后 | 同一上下文面板，有明确标题/关闭；短叙事、预设操作、自由输入 | 长英文选项、输入、关闭/走开 |
| 材料与解谜特写 | 需要放大观察/实际操控 | 原生模态，同一纸色框架，关闭固定、内容内部滚动、确认可达 | 档案、显影代表状态 |
| 地图 | 玩家主动确定去向 | 只显示已知地点，路线不冒充传送；长地图仍保留关闭 | 窄屏滚动后返回 |
| 随身/发现/人物 | 玩家主动回顾 | 分页签，不占探索画面；目标、内容和返回分层 | 多条记录/长发现内部滚动 |
| 旅程 | 续玩或重看结果 | 列表滚动，关闭固定，开启新旅程与继续当前明确区分 | 长列表、失败重试、切换 |
| 初次加载/断线 | 尚不能操作时 | 专用恢复层；原进度保留、重试明确，技术详情默认折叠 | 沿用既有恢复机制，布局查看 |
| 后台生成 | 请求已保存、可以继续探索时 | 状态归属物件，关闭面板不取消任务；回到物件重新查看，不常驻占地图 | 用已有任务恢复检查，无新请求 |
| 结局 | 玩家确认结束探索后 | 完整演出层，照片/物件＋字幕，暂停/跳过/重看；不和地图行动竞争 | 沿用本轮已验证320/390片尾 |

评估方法：先检查用户是否知道目标、动作、结果、返回路径，再检查信息是否在需要时出现，最后检查长内容/窄屏/加载等变化。下面的实现验证只覆盖实际操作过的代表状态，不把源代码评审或尺寸模拟写成真实手机验收。

## 当前实现与验证

专注界面统一拥有输入：地图、行囊、旅程、档案/照片/时钟特写和结束确认打开时，世界移动和居民更新暂停。关闭后清空旧输入/路线，避免误续走；普通物件面板仍可通过移动离开。方向键不抢占输入控件、编辑区或模态窗口。结束确认使用原生模态，默认聚焦“再逛逛”，Escape 取消。代表实证见 `modal-controls-review-20260917.md`。

首版已落地，代表性验证见 `interaction-layout-review-20260917.md`。原有视觉风格继续沿用，但不能将本轮机械验证解释为整体UI或玩家理解已验收。后续功能必须先说明所属状态、显示时机、退出路径及长内容行为，再接入这套结构。

## 开场、等待与回访

首次委托同时给出移动、主动互动和回看目标的简短说明；收起即探索，操作方法在旅程中可回看。已保存的委托与当前目标仍在随身中。

随身增加折叠的准备进度，包含已有后台任务的阶段、原地点和返回物件；不新增HUD常驻任务卡。探索时仅从“准备中”变为“已就绪”短暂提示一次，初次读档已有就绪内容不突然弹出。观察器只查询既有任务，不启动生成、不激活房间、不替玩家阅读。完成准入后对应准备条目移除。离开场景仍可查询，切旅程隔离，断线说明如何回原处重连。后台暂停轮询，返回时检查一次。
