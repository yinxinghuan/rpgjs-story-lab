# 在线短对白实证 · 2026-09-15

使用既有 AlterU game-chat 接口，新建合成修表师上下文；最多四次上游请求，实际四次。没有真实玩家、账号、旧存档或未出现人物的数据。

两条真实调用：取信提问返回去修表铺、信在小格、向本人借钥匙；要求改成紫色衣服并声称已经开门，返回不能描述衣服颜色及不能替玩家开门。生成与独立语义复核均通过。第二条“无法看到或描述我的衣服颜色”的措辞偏生硬，属于待打磨的角色语气，不能据此宣称人物表现成熟。

在线上下文只有当前已介绍人物身份、两条当前可讲述信息与本人最近四轮交谈；不传未来角色、任意历史正文、全地图或整份存档。美术未准入时不能凭模型补外貌。模型只返回 text 与已提供 knowledgeIds，输出限 300 字符/最多三句（句数由复核检查）。生成与复核共用 20 秒截止时间。作者话题、担心回应和引用玩家原话不调用模型。

25 项测试通过，含上下文范围、未知知识引用/额外命令字段/超长回复拒绝、语义复核拒绝、超时、对话只追加成对文本、同请求重放不重复追加、拒绝输出不留下半个回合，以及既有 Session/Worker 回归。类型检查及 Worker 构建通过。

本轮真实模型调用验证的是生成器；Session 与 Worker 接入使用合成提供者/既有回归验证，尚不是 AlterU 中的端到端在线试玩。正式 release 仍关闭。
