## 实际操作

本地测试服务使用隔离的 SQLite 旅程，不读取生产存档。前半段通过正常权威行动准备到地下室，浏览器从资料架开始操作：准备原始记录 → 开放侧门 → 实际走进档案间 → 查阅索引 → 查阅日志 → 到整理桌 → 返回地下室 → 再进档案间 → 独立刷新。

首次进入前未刷新页面；三件调查家具、四座储物架同时显示，剩余两个预登记储物槽保持隐藏。三个调查位置均可实际走到，桌面显示两处已读证据。往返与刷新后布局一致，已读状态保留。碰撞本体拒绝穿入及各接近点往返由共享真实寻路模块的定向测试验证；本轮没有把所有路线反复走一遍。
