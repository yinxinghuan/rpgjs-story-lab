# 最终空间层性能采样 · 2026-09-10

采样在 Mac 上的 Codex Chromium 152 浏览器运行，使用含最终遮挡代码的独立 Pages 测试构建；本轮没有 iPhone 真机测量。采样器挂在 Pixi renderer 的 postrender runner，统计实际提交间隔；这不是屏幕呈现帧率、GPU 完成时间或单独的 rAF 请求次数。

## 结果

| 实际 CSS 视口 | 采样 | 渲染间隔 p95 | 移动间隔 p95 | 最大间隔 | >40ms | 实际行走距离 |
|---|---:|---:|---:|---:|---:|---:|
| 390×844 | 10秒 | 10.1ms | 10.3ms | 13.9ms | 0 | 183.8 世界单位 |
| 320×568 | 10秒 | 9.9ms | 10.0ms | 12.7ms | 0 | 227.7 世界单位 |
| 1280×720 | 10秒 | 9.9ms | 10.0ms | 55.8ms | 1 | 227.6 世界单位 |
| 1280×720 | 30秒 | 9.9ms | 10.0ms | 64.2ms | 1 | 383.5 世界单位 |

全部样本主线程 longtask 计数为0，客厢含14个渲染事件（独立设备、座椅及NPC）。最长样本移动期间最大间隔14ms，单次报告位置步长最大1.144世界单位。桌面的两次离群间隔如实保留，没有以平均值掩盖；没有证据将其定位为GPU问题或声称所有运行条件都低于40ms。

实际 DPR 为1.3，画布缓冲分别为960×1440、672×1008、480×720；这是该浏览器当前缩放环境。最初两次300×649、320×567视口用于校准，未冒充目标尺寸。报告源为工具返回的日志，摘要保存在本机 `_qa/performance-results.json`。

## 如何复现

Node22环境，先构建独立测试目录：

```sh
CARRIAGE_QA_PERF=1 npm run build:pages -- --outDir dist-perf
npx vite preview --mode pages --outDir dist-perf --host 127.0.0.1 --port 5230 --strictPort
```

在浏览器打开该地址，实际核对 CSS 视口；选择10或30秒，按“开始采样”，正常点击地面或物件行走。采样期间避免并行构建等高CPU工作。记录移动样本数、实际距离、隐藏/失焦事件，不能仅根据“没有错误”认定路径已执行。采样器不读存档正文、凭据，也不存储或上传数据；输出本地控制台及只读文本框。

`CARRIAGE_QA_PERF` 只在构建时启用；普通 `npm run build` 必须不含 performance-probe chunk、采样面板与日志字符串，发布前机械检查。游戏动作与碰撞仍使用同一源码。没有为了测试改变生产镜头、分辨率上限、移动速度或图集。

## 后台恢复与未验证边界

早期 IAB 标签切换与访达 AX 操作没有触发 document.hidden 或 window.blur，因此这些样本不能证明后台恢复。首次原生操作遇到 Mac 锁屏；用户解锁后，改用 Chrome 原生键盘打开测试页，再以 Command-T 切走、Command-W 返回。此次实际记录到 blur 和 visibilitychange，未用脚本伪造事件。

解锁后的三个连续样本（Mac Chrome 152，604×849 CSS px，DPR2）：

| 操作 | 实际结果 |
|---|---|
| 点击检修柜寻路后切走 | 切走前移动15.598世界单位；1152.2ms时发生blur，位置(172.402, 80)；hiddenDuringSample=true、visibilityChanges=1、unfocusedDistance=0 |
| 返回后不发新移动输入，另采样30秒 | 移动样本0、距离0、最大位置步长0；未补跑原路线 |
| 再次点击检修柜 | 移动64.008世界单位、72个移动样本，并实际进入检修柜特写；可继续操作 |

隐藏样本在返回前已经结束，未记录到同一采样内的focus；因此使用返回后的独立静止样本与重新行动样本补证，而非宣称焦点事件成对齐全。原生标签隐藏是本次有效恢复证据；仅切换到访达的尝试仍无有效事件，不能冒充原生应用切换通过。记录见本机 `_qa/background-resume.json`。此前测试视口覆盖已reset。

源码的 visibilitychange 在页面隐藏时与 blur 共用清空键盘、摇杆、寻路和步态的方法；销毁时移除两个监听。40ms逻辑预算上限仍保留，原运动回归覆盖大间隔、薄墙、停止与到达。用户此前 iPhone“有所改进”的反馈不升格为真机性能全通过，Safari锁屏/操作系统挂起仍未在真机测量。

这些数据表明本机采样范围内新增遮挡层没有观察到持续卡顿；未做旧版/新版同环境对照，不能宣称开销减少。低功耗、热负载、DPR3及真实Safari持续性能仍不由本报告证明。
