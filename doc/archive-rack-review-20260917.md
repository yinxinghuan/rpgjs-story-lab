# 动态档案间：移架与查阅实证

本次完成生成房间中的一项实际空间行动：储物架挡住施工索引，走近后可向相邻空位移开，人物随后能走到索引前查阅；也可移回。复用当前游戏、Story Session 和已准入家具，不创建新游戏，不发布线上。

## 行为与实际修复

- 可选 `M/m` 代表一座架子及相邻水平空位。显示、碰撞、互动位置和寻路读取同一已保存布局与移动事实。移动前确实挡住索引的接近点，移动后索引才成为可接近目标；其他资料与退出路线仍可达。
- 右下角按钮直接提交移架/复位行动，自由输入仍共用同一权威规则。没有额外道具消耗、倒计时或结局条件；旧房间不被追加架子。
- 首轮浏览器检查发现：中文界面按钮被作为自由输入交给英文旅程，导致“无法理解”。已改为明确行动请求，复测移动和复位正常。移架结果缩短为一句，不要求为普通动作翻页。
- 切换旅程时，除了旧左右布局和人物版本，也比较实际房间布局；变化时重建 renderer，避免保留另一旅程的家具位置。

## 真实生成与实景

`campaign-live-20260917/movable-room-attempt-1.json` 记录两次现有平台模型请求，仅合成房间需求，无存档、账号或媒体调用。一份生成了有效左移布局；另一份把停车位与架子隔开，按现有规则拒绝。有效样本没有遵循额外固定储物架数量的要求，因此不能称为所有提示要求都满足。

浏览器回放使用此前单独生成的叙事与本次有效布局组合，不冒充一次联合生成成功。第一份合成房间经页面完成移开、走到索引查阅、移回；再切换到真实生成布局，架子和证据家具的位置确实改变。真实布局移架后查阅成功，独立刷新仍保持架子已移开及已查阅的索引。

- `blocked-390-platform-layout.png`、`shifted-390-platform-layout.png`：合成房间移动前后。
