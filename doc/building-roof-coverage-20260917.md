# 主要场景建筑屋面覆盖检查

依据：当前 `oldStreetConnections` 的通路数量、剧情用途和地面/室内/屋顶空间类型。以下“高频”是由地图结构推断，不是玩家遥测结论。

| 场景 | 通路数 | 处理 |
| --- | ---: | --- |
| 街口 | 3 | 地面枢纽，保持两侧连续建筑屋面，入口位于檐下。 |
| 合住院 | 5 | 最高连接度枢纽；西侧洗衣店/修表铺与东侧工作棚补成完整屋顶边界，替换孤立门口雨棚。 |
| 修表铺 | 2 | 重要室内，保留等高剖面墙与门洞；不覆盖屋顶遮住探索物。 |
| 照相馆 | 3 | 室内分支枢纽，同上。 |
| 洗衣店 | 1 | 室内，剖面墙；从院子已能辨认外部屋面和帘门。 |
| 河边工作棚 | 3 | 室内分支枢纽，剖面墙；院侧通过檐下门相接。 |
| 地下储物室 | 3 | 地下空间，保持围墙与阶梯，不增加地面屋顶。 |
| 屋顶 | 2 | 可探索屋顶本身即屋面，保留开放边缘；不加邻接可疑“道路”误导玩家绕过断口。 |
| 暗房 | 1 | 照相馆内部动态扩展房间，剖面墙。 |
| 档案间 | 1 | 地下动态扩展房间，剖面墙。 |

## 实施

`oldStreetBuildingRoofs(room)` 显式声明适用场景，仅 street/yard。院落每侧屋面宽36，檐下立面12，覆盖 floor.y 到 floor.y+floor.h。街口保持40宽。像素密度固定为源图每234（西）/230（东）像素对应40地图单位；边界宽度差由外缘裁切吸收，不缩放瓦片。立面按真实侧门切洞，屋顶连续。北侧地下阶梯及南侧街口巷道不加屋顶横封。

## 验证

4项定向测试通过：两个枢纽完整屋面跨度、全部侧入口处于立面凹口、屋面始终处于可走范围之外、其他8场景不误加屋面、环境依赖。真实 renderer 合成庭院总览及正常游戏合住院画面已检查；该项未改变通路逻辑，无需重复全剧情路线。正常游戏保持跟随镜头，靠近一侧显示该侧建筑，不为同屏塞下两侧屋面而缩小人物。截图见 `_qa/ui/hub-roofs-20260917/`。
