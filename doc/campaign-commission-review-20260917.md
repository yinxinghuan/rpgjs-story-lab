# 新主线动机与调查衔接检查（2026-09-17）

## 本次改变

仅新建 `letter-trail-v2` 旅程从开场说明家人托付两件事：取回密封信、查清随信寄存的旧街记录。纸袋提供片段和待查问题；档案生成读取该片段及问题，完成调查后把发现保存在旅程和结局中。原件带回或留在当地的选择保留。

已有普通、v1 和较早 v2 旅程不回填委托，不改历史开场。新材料要求问题；旧材料无该字段仍可恢复和继续。玩家没有阅读时，后台准备的内容不会提前进入自由输入知识或发现页。

## 当前局限与下一步

本轮没有调用真实模型或媒体，全部新内容使用明确标注的合成 fixture。它用于验证衔接，不用于证明成品故事质量。当前小桥示例的一个来源便能回答核心疑问，而完整顺序要求两处来源；因此不能把完成全部排序当作有意义调查深度的证据。

下一步评估两份真实生成的连续内容：片段是否引出值得追查的问题，后续证据是否真正必要，发现是否回答问题，选择是否产生可感知后果。需要依据结果调整内容结构，不能继续添加相同排序题来凑长度。45–60 分钟目标、完整单人游戏和新玩家理解仍未验证。

本次只更新开发分支，不部署、不打开正式 campaign 开关、不改真实玩家存档。技能正式更新仍排在完整 2D 探索结构验证之后。
