# 2026-10-04 全局可编辑例句：局部验收

## 批准与范围

用户直接批准旧街和交割之前的全局“举一个例子”，测试通过后直接发布。仅适配实际存在的自由文本输入；不增加模型、行动、后台、账号权限、云资源或美术。共享技能只读，由原负责人回写。

## 实现与覆盖

- 交割之前：人物自由对话。目标生成没有自由文本输入，不凭空增加入口。
- 旧街：人物交谈／物件行动共用输入；可编辑暗房提议。自动委托、工坊采纳和只读生成输出不属于此输入类型。
- 每个上下文两条短例句，依据已提交事实；完成优先，未知中性，不透露隐藏道具、未来答案或下一步结果。
- 空输入可填入；已有、编辑过或恢复的草稿先预览，明确替换／保留。填入后可改写，仍须原按钮手动发送。
- 请求等待、失败或父级禁用时不允许操作。上下文变化只重置辅助状态，不重置草稿；没有新请求 ID 或自动重试。
