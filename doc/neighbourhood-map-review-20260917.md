# 旧街导览地图 · 本地改版

用户反馈地图不够清晰直观美观。旧版截图实际看到：只有街口与照相馆时，固定全图画布保留大量空白，地点是同类方框，路线仅用一行地点名表达，缺少真实出口提示。

## 实现

沿用已选纸色、深绿手记界面。建筑用钟、相机、衣架、档案架等同系SVG地标；街口和院落采用圆形场地，当前位置深绿且标明“当前位置”。选点后即时显示路线、步骤序号和第一段场景出口；长路线可展开，每段取真实出口方向。不新增地图移动/传送或模型请求。

已知区域自动裁切，尚未到访房间不展示。地图与摘要分区滚动；窄屏打开时自动将当前地点滚入图内，短横屏采用左右两栏。连接是示意布局，不假装比例或实际方位；指引明确指“场景上方/下方/左侧/右侧”，避免示意连线与房间出口混淆。

## 验证与迭代

- 实际本地旅程在照相馆打开地图，仍只出现照相馆和街口；选择街口显示场景下方门的指引。只选择目的地不改变当前场景。
- 初版两地点在桌面仍过大，下方节点被截；限制图幅至380px后同状态复验，减少空白和截断。
- 真实生产组件配合本地合成存档夹具检查全10地点，不对玩家存档灌入状态。390×844英文全图、320×568不可达目的地、844×390中文解锁路线均有截图。
- 阻塞时从街口到工作棚走照相馆→屋顶（3段）；开门闩后走合住院（2段），高亮与文字一致。暗房未开放时明确不可达，关闭始终可用；展开完整路线展示每段出口。
- 320宽无横向溢出；初始开图当前位置在图的可见滚动区。390宽各地点触控约94×76px或94×87px。
- 既有2项地图核心测试覆盖未到访隐藏、阻塞绕路、解锁快捷路径、恢复和不改写存档；通过。不逐条重复测试所有游戏路线。
