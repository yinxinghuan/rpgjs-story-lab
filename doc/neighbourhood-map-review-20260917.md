# 旧街导览地图 · 本地改版

用户反馈地图不够清晰直观美观。旧版截图实际看到：只有街口与照相馆时，固定全图画布保留大量空白，地点是同类方框，路线仅用一行地点名表达，缺少真实出口提示。

## 实现

沿用已选纸色、深绿手记界面。建筑用钟、相机、衣架、档案架等同系SVG地标；街口和院落采用圆形场地，当前位置深绿且标明“当前位置”。选点后即时显示路线、步骤序号和第一段场景出口；长路线可展开，每段取真实出口方向。不新增地图移动/传送或模型请求。

已知区域自动裁切，尚未到访房间不展示。地图与摘要分区滚动；窄屏打开时自动将当前地点滚入图内，短横屏采用左右两栏。连接是示意布局，不假装比例或实际方位；指引明确指“场景上方/下方/左侧/右侧”，避免示意连线与房间出口混淆。

## 验证与迭代

- 实际本地旅程在照相馆打开地图，仍只出现照相馆和街口；选择街口显示场景下方门的指引。只选择目的地不改变当前场景。
- 初版两地点在桌面仍过大，下方节点被截；限制图幅至380px后同状态复验，减少空白和截断。
- 真实生产组件配合本地合成存档夹具检查全10地点，不对玩家存档灌入状态。390×844英文全图、320×568不可达目的地、844×390中文解锁路线均有截图。
- 阻塞时从街口到工作棚走照相馆→屋顶（3段）；开门闩后走合住院（2段），高亮与文字一致。暗房未开放时明确不可达，关闭始终可用；展开完整路线展示每段出口。
- 320宽无横向溢出；初始开图当前位置在图的可见滚动区。390宽各地点触控约94×76px或94×87px。
- 既有2项地图核心测试覆盖未到访隐藏、阻塞绕路、解锁快捷路径、恢复和不改写存档；通过。不逐条重复测试所有游戏路线。
- 完整构建（含 Worker 启动检查）、公开凭据扫描、diff 检查通过。UI静态审计的新地图源文件无命中，历史构建目录的第三方提示保留为既有噪声。英文/中文及门/楼梯/通路指引均已在实际组件中检查；新版方向文案已确认进入最终构建。

证据：`_qa/ui/neighbourhood-map-20260917/`。已用修改后的实际组件验证布局与选择；地图是否足够直观仍待用户试玩评价，不能以机械测试宣称新玩家理解通过。地图版未上线，线上只包含此前对话修正。

## 追加反馈：直接命名与出口方向

用户指出连接图方向不符合真实游玩。旧全街节点布局已撤下，改成当前房间附近图；出口位置从运行时 `oldStreetDoors()` / `oldStreetFloors` 投影，相邻地点放在该出口所在侧。同侧多个出口按真实前后顺序排列；远处地点通过选择目的地获得路径及下一出口高亮。没有改门位置、关卡通路、存档或传送行为。当前仍是附近示意图，不是全街地理总图。

功能入口统一“地图 / Map、背包 / Backpack、菜单 / Menu”；背包分类“目标 / Objective、物品 / Items、线索 / Clues、人物 / People”；菜单“存档 / Saves、新游戏 / New game”。入口说明与无障碍名称同步。

验证：3 项地图测试通过，覆盖全 24 个方向端点、同侧排序与间隔、隐藏未到访地点、路线阻塞及解除、不写存档。真实主界面核对地图/背包/菜单；隔离 UI 使用真实地图组件及合成全地点存档，检查 390×844、320×568、844×390。照相馆上方屋顶、下方街口、右侧暗房；街口左右店铺；庭院两处左侧出口没有重叠。远处目标选择后列表收起、回到附近图并突出第一段出口。小屏内容滚动，不缩小触控目标。未重复全剧情，未宣称真人空间理解已验收。
