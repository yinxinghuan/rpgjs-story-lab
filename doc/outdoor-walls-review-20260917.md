# 全场景上下墙体补齐

玩家要求室外也有顶部墙面和底部遮挡。本轮覆盖上一轮“只补室外两侧屋顶”的范围判断。

- 室内七处原64单位等高墙保留；街口、合住院、屋顶增加32单位等高院墙/女儿墙（包含8单位压顶）。室外以正常院墙比例处理，不拉高成室内墙。
- 上方石墙在人物后方，下方石墙在人物前方；共享局部淡化以保持近墙角色可见。两侧连续建筑屋顶保留。
- 阶梯、侧门、巷道从权威位置开槽；街口南端额外沿回家实体位置留口。没有新增或改变通路。
- 复用石阶内干净石材区域，无新生成，无额外素材下载。

验证：7项室内/室外墙、动态开口、局部遮挡、装饰裁切及通路接近点测试通过。真实RPG-JS合成预览分别检查合住院、屋顶、街口的上墙/下墙/出入口；预览不含家具与剧情道具，因此不把该证据称为完整剧情试玩。正常游戏也已挂接相同组件，保留用户当前所在修表铺，不替用户转场。
