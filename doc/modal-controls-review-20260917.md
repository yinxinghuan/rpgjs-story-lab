# 专注界面与世界输入隔离

## 发现与修改

系统评估发现：结束确认使用普通 div 遮罩，阻止了触摸却未暂停 renderer 的全局键盘移动；动态照片也没有进入主界面统一的模态状态。输入监听还会拦截模态内非输入按钮的方向键。

现在旧街地图、行囊、旅程、各特写、结束确认共用 modalOpen；renderer 独立检查 controlsBlocked。专注界面出现时清空旧按键/摇杆/路线，暂停移动与居民；异步请求释放自身 pause 时也不能恢复背景移动。编辑区、模态内部、组合输入、浏览器快捷键不触发走路。普通物件/对话面板保留移动离开的行为。

结束确认改用原生 dialog，Stay 默认焦点，Escape 取消；仍走原有服务端结束行动，不改存档、门槛或后果。

## 本地验证

继续上一轮明确创建的合成旅程，真实界面执行：

- 在暗房查看已保存照片，模态期间摇杆 disabled；方向键不触发世界操作，Escape 收起后能继续步行至照相馆门并进入。
- 沿照相馆→街道→回家入口实际走动，以统一右下按钮打开操作，再打开结束确认。
- 确認默认聚焦 Stay；Tab 到 Go home，背景未成为活动目标；Escape 取消后保留原旅程并恢复摇杆。
- 320×568 重新打开，DOM 确认 `dialog:modal` 成立、焦点为 Stay、页面宽/滚动宽均320；长英文借物说明及两个选择完整可见。
- 明确点击 Go home 后进入现有9段结局演出；没有点击确认前不会结束。

截图 `_qa/ui/modal-controls-20260917/` 为 platform-layout（操作关闭外部访客栏）。本轮没有在线模型、媒体生成、真实玩家存档读取或生产部署。只有局部段落实走，不是从开场完整全程验收；真实 iPhone 键盘仍未验证。

9 项输入、显影与恢复测试通过；完整构建通过（9 场景/27 资源 SHA、Worker 启动）。既有 bundle 体积、旧列车图片/音频编译期引用警告仍在。

## 阶段判断

统一显示时机、操作层级、等待回访、自然入口、模态输入已形成可运行的本地 UI 基线。继续以全界面矩阵约束新增内容；不为同一类状态反复跑所有路线。接下来优先推进第二阶段的动态中段调查差异和选择后果，保留真实平台/真机及玩家理解为综合验收项，不能宣称完整单人游戏已交付。
