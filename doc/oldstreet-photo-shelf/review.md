# 地下室搁架与照片夹候选

一次平台edit生成1024×512原图，任务和哈希见state.json。保留原图，通过制作页共享magenta-matte-unmix-1去底和两帧脚点对齐，输出cutout.png及preparation.json。

原图没有遵守所有布局要求：左侧是带下格的短搁架，右侧是竖向平面照片夹，并非指定横向夹子。搁架无门、无独立其它物品，继续对应原有32×28障碍。平面夹子在renderer按.08/.055两轴投射，固定在搁架顶部；搁架自身等比.125，不拉伸家具。没有显示照片内容或提前泄露拼图答案。

old-street-photo-shelf.ts提供两个共享事件图层。photos-taken为真时只隐藏夹子，搁架仍显示；归还摄影师不重置该事实。场景重建和同场动作更新均读取StorySave，原碰撞、接近点、动作与模型合同不变。仅?shop_art=pixel入口启用，默认入口不变。

规则测试经拿取、拼照、归还及JSON恢复确认空架保持，80项探索回归及类型检查通过。去底PNG已只读检查。实景CUA新开页超时，随后getState明确报告Mac锁定且自动解锁失败，未获得当前地图截图。**实际尺寸、遮挡、去底边缘、拿取后立即隐藏及跨场景恢复待真实renderer复验，不准入正式美术，不上线。**
