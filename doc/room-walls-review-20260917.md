# 室内墙体与遮挡统一

## 已处理

此前只有修表铺、照相馆和工作棚有独立上墙，其他房间多为地板裁切加边框；墙面与下沿也没有共同的遮挡合同。本轮统一七个室内的墙体几何，保留各房间材质和已有墙上细节。上墙、侧边、下沿矮剖面共同构成室内轮廓，实际门洞始终留空。

- P1：室内上墙有无不一致 → 七个室内都绘制64单位上墙。
- P1：人物永远浮在地板边框上 → 24单位前景剖面墙真实覆盖 canvas 中的腿部，人物头肩仍可辨认。
- P1：新墙可能挡住出入口 → 门洞由权威门坐标切段；未准入的暗房/档案入口保持实墙，准入后同位置开槽。
- P2：房间墙边高低、厚度不一致 → 墙顶厚度和侧边统一；旧墙面装饰也从共享几何派生。

## 证据与范围

`_qa/ui/room-walls-20260917/` 保存七个室内的390宽度检查、洗衣店相同站位前后对照、320×568贴墙与门洞，以及实际游戏照相馆的 platform-layout 证据。

隔离页面使用真实RPG-JS renderer和主角精灵，但省略家具与剧情，专门检查建筑层；实际游戏页面补验角色行走、前景遮挡、出口可见及右下行动可用。检查从左侧贴墙移动到门洞时，腿部由遮挡恢复为完整可见。原地图碰撞与门坐标未变，未重复通关各条剧情路线。

7项相关自动检查通过：墙体空间合同2项、环境下载2项、三种已有墙面裁切3项。构建包括空间校验、所有场景产物哈希和Worker启动检查。静态UI扫描的历史dist-*第三方bundle命中单独记录，不作为新源码缺陷。
