# 地面、屋顶与门素材目录

当前是随项目分发的本地素材库，不需要部署数据库。

- `catalog.json`：地面目录，原有准入规则不变。
- `roof-catalog.json`：首批四种屋顶，含稳定ID、材质类型、PNG来源/哈希、图像尺寸、裁切、世界尺度、采样密度、檐沟是否在原图内、准入状态及评审链接。
- `getRoofMaterial(id)` 默认拒绝候选；本项目显式使用 `allowCandidate:true` 做本地验证。其他游戏不得把候选静默当成认可基准。
- `roofMaterialSampling(id)` 将构件世界尺度与像素采样分离。当前用户认可的旧屋顶纹理宽80地图单位、每单位2像素，最近邻保留颗粒；可见屋顶宽仍36/40，超出部分从外侧裁切。
- `RoofMaterialSurface` 为通用SVG显示组件：传材质ID、已加载图像URL、位置尺寸和檐沟朝向；一次Canvas采样后缓存，SVG仅负责按原世界尺寸重复。独立于剧情/碰撞。
- 新材质：平台生成→检查真实图像→登记来源与crop→声明worldWidth及pixelsPerWorldUnit→放到目标镜头比较→评审状态。重复接缝未验收时保留 `seamless:unverified`，不得仅因提示词写了seamless就宣称无缝。
- 场景分配位于 `old-street-roof-materials.ts`；同一建筑前后材质相同，变化发生在建筑之间，不随刷新随机切换。

本地对照：`/_qa-roof-materials.html`，不进入正式构建入口。

## 门素材库

`door-catalog.json`是已登记门款式的真源；目前有两款用户认可的本地素材：内收斜开与90度开门。更早的`door-wood-olive-simple-01`因消失点透视仍标为`rejected-projection`，不能把待制作种类当成已有资产。木门、玻璃门、铁门、卷帘、半扇门可以按需要扩充，准入前仍需独立生成和实景检查。

门图只带门框、门扇、门槛，可有少量顶梁表面；禁止自带整块墙、石柱基座或大片地面。周围墙和屋檐由场景负责。每项有稳定id、造型类别、来源与hash、投影、支持朝向、开/关图格、统一门槛脚点、世界尺度和前景结构区域。门洞/碰撞/路线继续由地图定义，不能由图片创造。

正面图支持N/S，不能转90度用作W/E侧门；侧向需要独立准入。造型按建筑/门的id稳定选择，加载、刷新或开关时不能随机换门框。动态生成同样遵循这些元数据及审核规则，缺失时使用匹配朝向的已准入回退；不直接用未知尺寸图片替代。

新增款式以真实人物比例、同场景墙面、开/关固定脚点及前景遮挡作验收，不能把当前橄榄绿色木门的外观强制作为所有建筑的唯一款式。

投影验收：正面顶梁/门槛的前后横边等长且平行、纵深边不收拢，开门扇的上下边平行且等长。正交不等于没有顶面；禁止靠压扁门或加墙条遮住楔形缝。原候选保留，默认游戏未采用被拒素材。

### 当前已接受门款（2026-09-18）

用户认可 `door-wood-olive-inset-01` 内收斜开与 `door-wood-olive-open90-01` 90度开门，两款正式登记为本地可用素材。当前库存以door-catalog.json为准。窄通道优先90度、宽裕位置可斜开；按入口固定选择。两款来源均为Codex图像生成，不记作平台产物。原始的向框外伸出门扇及带消失点简框仍不准入。接受当前效果不等于没有瑕疵，也不强制其他门复用同一外观。

### 平台生成优先版本（2026-09-18）

`door-wood-olive-inset-platform-01`与`door-wood-olive-open90-platform-01`为本轮平台生成并实景检查的两款。`preferredByPose`及`getPreferredDoorMaterial()`现在优先返回平台版本，Codex原认可图仍按原ID保留。两项的图片hash、任务ID、开闭列、脚点和比例来自实际输出，不继承错误的来源标签。

生产方式：认可参考图→平台edit轻改纹理并保留几何→自动去背景/脚点对齐→北/南开闭代表检查→登记优先项。90度首轮曾被误绘为宽面板，必须看输出。当前只验证了有参考编辑，不能当成无参考随机文生图的稳定性结论。详细证据见`doc/door-platform-20260918/review.md`。

### 实际消费（2026-09-18）
默认游戏已接入两款平台正面图、专用W/E侧门和回家双扇门。侧门图包含门槛/木框纹理，立面厚度由`SideDoorway`按照房间墙高组合；不可将单张俯视图宣称为有厚度的完整门。开/闭列顺序按catalog读取，侧门与正面图的列顺序不同。`side-plan`仅木地板方案因像垫子未准入；`side-orthogonal`正面误绘亦排除。

用户否决侧向组合后：`door-wood-side-sliding-platform-01`已降为`rejected-composition`，运行回退旧侧向素材，侧门尚未完成。独立空间样片确认之前不再接入。正面与回家门接入保留。

### 最终侧门库（2026-09-18）
上述rejected-composition不再回退为运行素材。当前实际库存见`side-door-catalog.json`：平台短过门石、普通olive/clock门板、原生左铰watch shop与右铰photo studio门板。全部门板整图去底，几何厚度由场景提供。门洞56、门板48地图单位；上侧铰接，开向逐连接设置，碰撞与渲染共用同一配置。过门石亮度0.82、饱和度0.88。生成入口为`src/door-generation-recipe.ts`，未经视觉审核的新输出不能直接替代准入项。
