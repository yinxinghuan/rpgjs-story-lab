# 验证

`npm test`运行纯规则、SQLite及fake-indexeddb持久化测试。浏览器版两条完整路线与SQLite逐步对照，并覆盖关库重开、同请求重放、并发提交、越场景操作与自由输入不发奖。

开发过程的录屏、会话数据、日志和截图不进入公开仓库。手机实体Safari测试由玩家通过线上入口执行；尺寸预览不是实际设备帧率证据。

性能测试按 `doc/performance-review.md` 使用显式 CARRIAGE_QA_PERF 构建。普通发行构建不得包含采样器；postrender 间隔只代表当前浏览器渲染提交。必须确认实际 CSS 尺寸、移动样本和可见性事件，不能把无效切后台或视口校准样本记作通过。
